How to create a Wi-Fi QR code

A Wi-Fi QR code stores the network name (SSID), the security type, and the password in a standard format many phone cameras can read. Guests can scan it instead of typing a long key. Create the code locally with Free QR Code Creator.

Steps

  1. Open the QR tool and choose the Wi-Fi option. On Free QR Code Creator, select the Wi-Fi (or WLAN) content type if it is listed. If you only have a text field, use the standard WIFI: payload format your tool documents, including the network name, password, and security type such as WPA.
  2. Enter the exact network name and password. Copy the SSID and password carefully. A single typo means the scan will fail. Include spaces or punctuation exactly as they appear in the router settings.
  3. Generate and test with a second device. Create the code, then scan it with a phone that is not already on the network. Confirm that the phone offers to join and that the connection works.
  4. Download and print or display the image. Save a PNG of the code and print it at a size that is easy to scan, with a quiet white margin around the code.

Treat the printout carefully

Anyone who can scan the code receives the network password. Do not post it in a public place if the network is private. For visitors, use a guest network when you can.

If a phone does not join

Check that the security type matches the router (often WPA or WPA2). Hidden networks and captive-portal hotel Wi-Fi may not work with a simple QR code.
